# Siheng Xia — Academic Homepage

Personal academic website built with Jekyll and the Minimal Mistakes remote theme.

## Local preview

1. Install Ruby and Bundler.
2. Run `bundle install`.
3. Run `bundle exec jekyll serve`.
4. Open `http://localhost:4000`.

## Publish

The repository is prepared for the GitHub user site `sihengxia126.github.io`. Push the `main` branch to a public repository with that exact name, then select **GitHub Actions** as the Pages source under **Settings → Pages**.

## Update content

- Site identity and links: `_config.yml`
- Top navigation: `_data/navigation.yml`
- Homepage: `index.md`
- Research, publications, experience, and CV: `_pages/`
- Visual design: `_sass/_custom.scss`
